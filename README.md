# 🍕 Pizza Sales Analysis (SQL Project)

This project demonstrates how to analyze pizza sales data using **SQL**. It includes a comprehensive set of queries to extract key performance indicators (KPIs), identify sales trends, and evaluate product performance. The results are documented in a Word file with query outputs and visual screenshots for clarity and presentation.

## 📌 Project Objective

The goal of this project is to showcase how SQL can be used to perform business analytics on transactional data. It covers both foundational metrics and advanced breakdowns to support decision-making in a retail food context.

## 🗂️ Documentation

All SQL queries and their results are compiled in a Word document:

- `Pizza_Sales_SQL_Analysis.docx` – Contains:
  - SQL queries for KPIs and charts
  - Screenshots of query results
  - Commentary on insights derived from the data

## 🧮 Key Metrics Extracted

- **Total Revenue:** $817,860.05  
- **Total Pizzas Sold:** 14,975  
- **Total Orders:** 21,350  
- **Average Order Value:** $38.33  
- **Average Pizzas per Order:** 2.32  

## 📊 Trend Analysis

### 🗓️ Monthly Order Trends
- Highest orders in **December (2,566)** and **January (2,364)**  
- Consistent performance across months with slight dips in February and September

### 📅 Weekly Order Trends
- Weekly breakdown using `DATENAME(WK, order_date)`  
- Useful for identifying peak operational weeks
